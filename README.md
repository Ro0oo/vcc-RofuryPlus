## What is RoFury+?

RoFury+ is a community-made **add-on for** [**VRCFury**](https://vrcfury.com). It adds a pile of quality-of-life upgrades to VRCFury.

> **Requires VRCFury.**

---

## Install

1. **Add to VCC** — click the button above, then hit **Add to VCC** on the listing page. Your Creator Companion opens with RoFury+ ready to add.
2. **Add it to your project** — in VCC, open the avatar project you're working on and add the RoFury+ package.
3. **Open Unity and build** — use the RoFury+ tools in the Unity toolbar and start creating. VRCFury handles the rest.
