## What is RoFury+?

RoFury+ is a community-made **add-on for** [**VRCFury**](https://vrcfury.com). It adds a pile of quality-of-life upgrades to VRCFury.

> **Requires VRCFury.**

---

## Install

1. **Add to VCC** — click the button above, then hit **Add to VCC** on the listing page. Your Creator Companion opens with RoFury+ ready to add.
2. **Add it to your project** — in VCC, open the avatar project you're working on and add the RoFury+ package.
3. **Open Unity and build** — use the RoFury+ tools in the Unity toolbar and start creating. VRCFury handles the rest.

Button not working? Add this repo URL manually in VCC → Settings → Packages → Add Repository:

```
https://ro0oo.github.io/vcc-RofuryPlus/index.json
```

## Patch Notes

### v2 · Latest release

**New**

* **Hue Shift Generator** — generate hue shifts that just work across PC, Quest & Particles.
* **The Blendshape Panel** — make blendshapes fun and easy. A few clicks is all you need.
* **UI Improvements!** — a pile of Unity upgrades to the Hierarchy, Inspector and Project tab.
* **Where are my toggles?** — a new Find button on toggles. No more endless scrolling.
* **Icon Panel** — snap menu icons for your toggles and folders straight from your avatar.
* **Leader Toggle** — ONE Toggle to Rule Them ALL. A toggle that turns other toggles on and off.
* **Conflict Force** — let two toggles turn the same object on and off without VRCFury yelling at you.

**Improved**

* **Drag & drop everything** — move toggles and folders anywhere in the main panel.
* **MORE Actions** — see every action at a glance.
* **Outfit Creator, leveled up** — now links your Armature and turns PhysBones off with the outfit.
* **Rename Paths** — ~~the Bulk Path Manager~~ got renamed and optimized.
* **Settings & Performance!** — you have control.

**Fixed**

* **Slashes** — names with a / in them no longer get mistaken for folders and split in two.

**RIP**

* <b>~~Visual Path Tree Editor~~</b> — the Main Tab took over (he does exactly what I do, BUT better).

### v1 · First release

**New**

* **Smart Outfit Creator** — drop in clothing and RoFury+ wires the armature for you, with **Auto-Shrink Blendshapes** to kill clipping automatically.
* **Visual Path Tree Editor** — see your whole avatar hierarchy as a tree. Find, retarget and fix broken paths without hunting through the inspector.
* **Bulk Path Manager** — rename dozens of paths at once.
* **Copy / Paste Actions** — copy toggles, actions and whole setups between avatars. No more flipbook page pain T^T.
* And a little more to discover on the way.
